# SoulAlcove

[English](./README.md) | **Русский**

> Приватный дневник настроения для Android, который не покидает ваш телефон.

SoulAlcove — это минималистичный трекер настроения и эмоциональный дневник для Android. Без аккаунта, без облака, без рекламного трекинга — только вы и ваш день.

## Возможности

- **Отметка настроения в один тап** — выбрал цвет, готово.
- **Короткие заметки** — при желании добавь мысль к любой записи.
- **История по дням** — просматривай свою эмоциональную ленту в чистом и спокойном интерфейсе.
- **100% локально** — все данные хранятся на устройстве в SQLite. Ничего никуда не отправляется.

## Почему SoulAlcove

- **Приватность по умолчанию** — эмоциональные данные никогда не покидают телефон.
- **Без регистрации** — открыл приложение и сразу начал.
- **Работает офлайн** — полностью функционирует без интернета.
- **Лёгкое** — ничего лишнего, никаких ненужных разрешений.

## Технологии

- **Python** + **Flet** / **KivyMD** (Android GUI)
- **SQLite** для локального хранения
- Без бэкенда и внешних серверов

## Статус

Первый публичный релиз для Android. Основной опыт готов: быстрое логирование, читаемая история, полная локальная приватность.

В планах: инсайты, мягкие серии и лучшие способы оглянуться на свои эмоциональные паттерны — и всё это по-прежнему local-first.
